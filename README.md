# Dev Kumar — Streaming Media Ecosystem

Static, responsive portfolio for streaming media frameworks, playback systems, AirPlay-style device connectivity, and partner-facing APIs. It has no framework or build step and is ready for GitHub Pages.

## Run locally

Open `index.html` in a browser or serve this directory with a static HTTP server. `ecosystem-bg.svg` is the animated, locally stored background artwork; `styles.css` and `script.js` power the layout, transitions, animated text, project filtering, and experience accordions.

## Apple and role research

The Apple posting is for a senior media application engineer in Media, Graphics and Compute Technology. The Streaming Media Engineering team delivers playback technology for Apple and third-party devices through AirPlay. The work spans next-generation experience design, technical direction, system architecture, APIs for partner adoption, cross-functional engineering and design, issue resolution across the media framework, SDK, and connectivity layer, and quality improvements to playback, connectivity, and reliability. The posting names C/C++, Objective-C, JavaScript, audio/video codecs (H.264, HEVC, AAC, AV1), networking, HLS/DASH, HTML5 MSE/EME, and mobile or embedded players.

Apple developer documentation frames this as an ecosystem problem: AVFoundation underpins time-based media across Apple platforms and supports HLS playback; HLS adapts among available streams as network conditions change; AirPlay involves route discovery/selection and enhanced buffering, while apps can support remote-control and playback behaviors. From those sources, the central engineering challenge is balancing compatibility, partner APIs, transport conditions, codec capabilities, startup and rebuffering behavior, and reliability while keeping the user experience simple. The portfolio emphasizes those themes through its route-to-playback diagram and telemetry narrative without stating that its content is tailored to a particular job.
